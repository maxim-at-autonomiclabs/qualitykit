SEO MCP for Next.js codebases

QualityKit is a Model Context Protocol server that audits SEO where the code lives. Agents call qualitykit.audit, qualitykit.grow, and qualitykit.fix — you approve diffs; QualityKit never writes the repo.

What it does

  • Inventories routes, robots, sitemap, metadata, and schema
  • Separates defects from growth opportunities
  • Returns advise-only unified diffs for technical fixes
  • Emits buildContracts for new landing pages so the host agent implements them in your stack
  • Verifies findings and route presence, then records shipped changes when Search Console is connected (Pro)

How it works

  1. Install the MCP in Cursor (or any MCP host)
  2. Run qualitykit.grow for top impression-oriented changes
  3. Apply technical diffs from qualitykit.fix; implement page contracts with your agent
  4. Call qualitykit.verify, then visibility.mark_applied after deploy

Free locally. Pro for measurement.

Local audits, grow, fix, and verify stay free. Pro adds Search Console sync, opportunity backlog, and change baselines so you can compare impressions and clicks over time. Search Console data often lags 1–3 days, and period deltas are correlational — not a ranking guarantee.
