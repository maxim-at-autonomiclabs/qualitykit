How to run an AEO MCP session

A practical checklist for AI discoverability with QualityKit. Prefer one clear pass over mass-generating content.

1. Connect the MCP

Add QualityKit to Cursor (or your MCP host) with npx -y qualitykit. Point tools at the absolute projectRoot of your Next.js or static site.

2. Audit and AI audit

  1. qualitykit.audit — fix blocking indexability before new pages
  2. qualitykit.ai_audit — note low scores and evidence (not citation guarantees)
  3. qualitykit.grow — review needsApproval page ideas

3. Approve, then implement

Ask the agent to present grow ids before writing. Call qualitykit.fix with approved finding or opportunity ids. Apply technical diffs; implement buildContracts in your stack’s patterns.

4. Verify and record

qualitykit.verify with opportunityIds checks route presence. After deploy, Pro users call visibility.mark_applied so the backlog marks shipped and GSC baselines are stored. Period deltas later are correlational.
