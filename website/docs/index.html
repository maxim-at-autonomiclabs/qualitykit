Docs

QualityKit is a read-only MCP server. It audits Next.js repositories, scores AI readiness, and proposes advise-only fixes. Your coding agent applies changes.

Install

npm install -g qualitykit
# or
npx -y qualitykit

Cursor MCP

{
  "mcpServers": {
    "qualitykit": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "qualitykit"]
    }
  }
}

Primary tools

  • qualitykit.audit — defects vs opportunities, route inventory, optional rendered HTML
  • qualitykit.grow — grow impressions: why visibility is limited, top 10 changes, safe vs approval (GSC enrichment when Pro API key is set)
  • qualitykit.ai_audit — AI discoverability scores with evidence
  • qualitykit.plan — content briefs, blog plan, schema, links
  • qualitykit.fix — unified diffs / file specs (never writes the repo)
  • qualitykit.verify — fixed / remaining / regressed
  • monitor.status — hosted Pro run when QUALITYKIT_API_KEY is set; otherwise self-hosted stub
  • visibility.report — Search Console period metrics + ranked opportunities via Cloud when API key is set; otherwise not_connected

Free vs Pro

  • Free: audit → grow → approved fix → verify. Explains impression blockers from the codebase. No account. No OpenAI key inside QualityKit.
  • Pro: daily crawl, run history, email regressions, monitor.status, plus Google Search Console connect/sync for the monitored site.
  • GSC: last 28d vs prior 28d impressions/clicks, optional deploy baseline, and re-ranked opportunities in visibility.report / qualitykit.grow when QUALITYKIT_API_KEY + QUALITYKIT_API_BASE are set.

Tool responses include additive schemaVersion and coverage. Never treat not_run as a pass. Model tokens are your agent’s — not QualityKit-funded.

Safety

  • Advise-only: no automatic file writes
  • Absolute projectRoot; skips .env* and common secrets
  • Ask before changing AI crawler allow/disallow rules
  • No ranking or citation guarantees
  • No mandatory signup for local MCP; no paywall on local fixes
